# QuePlan · Asistente documental de pólizas (demo)

Asistente que responde **solo con citas** de las pólizas del Depósito de la CMF
(corpus local) o de fuentes web de mercado. No decide ni tarifica.

## Preguntas útiles para la demo guiada

1. ¿Cuál es el plazo para denunciar un siniestro?
2. ¿Cuáles son las coberturas que ofrece la póliza de salud?
3. ¿Qué limita la cobertura cuando hay preexistencias?
4. ¿Cuántos planes de isapre hay vigentes en Chile para 2026? *(fuente web)*
5. ¿Cuáles son los beneficios del plan de estadio del Banco de Chile? *(fuera de las fuentes)*

Cada respuesta incluye las **fuentes** citadas (póliza · artículo · página), y las
externas se marcan como `[web]` para no confundirse con el corpus.
